## What I work on
 
- **Agent orchestration:** multi-agent pipelines, MCP servers and tool design, with pause-and-resume state and human-in-the-loop approval
- **Retrieval and evals:** hybrid retrieval over pgvector, scored test sets before any UI gets built
- **Local and on-device inference:** open-weight models on constrained hardware, with deterministic fallbacks when the model or network fails
- **Full-stack delivery:** typed frontends, async Python backends, containerised and deployed to the cloud
